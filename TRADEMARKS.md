# Trademark policy

The MyPack source code is licensed under the [Apache License 2.0](LICENSE). That
license covers the code. It does not cover the name "MyPack" or the MyPack logo
and app icon (the "Marks").

## What you can do without asking

- Say that your project is "based on MyPack" or "a fork of MyPack".
- Use the name to refer to the official project, for example in articles,
  tutorials, comparisons and package listings that point to the official
  releases.
- Build and use MyPack from source for yourself or inside your organization.

## What needs permission

- Distributing a modified build under the name "MyPack" or with the MyPack logo
  or icon. Forks that you distribute should use a different name and icon.
- Using the Marks in a way that suggests your product, service or website is
  official or endorsed by the MyPack project.
- Using the Marks in a company, product or domain name.

## Why

Official MyPack builds are signed, and their runtime registry is signed with
the project's key. People who download something called "MyPack" should get
exactly that. A different name for forks keeps that promise clear for everyone.
